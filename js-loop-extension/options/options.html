JS Loop Runner 配置

配置定时循环执行的 JS 代码、循环间隔和目标返回值。

建议不小于 100ms，避免影响页面性能
返回值匹配此值时，停止循环并发送通知。留空则不启用停止匹配。

使用说明
  • JS 代码中使用 return 返回值，每次执行的结果会与「目标返回值」比较。
  • 代码运行在页面上下文中，可以访问页面的 DOM 和 JS 全局变量。
  • 循环会在匹配目标返回值后自动停止，并发送浏览器通知。
  • 点击插件图标打开弹窗，在弹窗中启动/停止当前页面的循环。
